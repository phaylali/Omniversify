## Overview

A premium, offline-first Flutter application designed to explore and preview Tifinagh fonts with a **Moroccan Luxury** aesthetic. Browse, search, and preview authentic Tifinagh typography from IRCAM, Tawalt, and other sources.

## Features

- **Moroccan Luxury Design** — Gold, Glassmorphism, and Pure AMOLED themes
- **Font Discovery** — Instant access to over 350+ unique Tifinagh fonts
- **Real-time Preview** — Type any text to see it rendered across all fonts instantly
- **True AMOLED Mode** — Pure black (`#000000`) theme optimized for OLED screens
- **Dual Formats** — Supports both OTF and TTF with direct links to source files
- **Offline-First** — All fonts bundled locally, no data tracking

## Themes

- **Space Mode** — Professional pure black AMOLED with sharp gold borders
- **Moon Mode** — Modern dark grey theme for a soft, premium feel

## Font Sources

350+ fonts across multiple collections, including:

- **IRCAM Collection** — Adlis, Afulki, Azurar, Tabarawt, Tadlagt, TifinaghEcran, TifinaghRevue, and 25+ official IRCAM fonts in OTF + TTF
- **Tawalt Collection** — Kabaw variants (200+ fonts), Tanes, Nfusa, Amawal, Unicode, Borawy 200 series
- **Other Variants** — Akatab (Black, Bold, ExtraBold, Medium, Regular, SemiBold), Hapax (Berbère, BAPT, DzN, Tifinar, Yugurten), Tagmukay, Damase, and more
- **Standard Fonts** — NotoSansTifinagh, DejaVu Sans, FreeSans, CODE2000, Quivira, and others

## Quick Start

```bash
git clone https://github.com/phaylali/Tifinagh-Fonts-Viewer.git
cd Tifinagh-Fonts-Viewer
flutter pub get
flutter run
```

## Design Decisions

- **No Accounts** — Utility tool, PocketBase and accounts intentionally omitted
- **GitHub Links** — Font files link directly to `blob/main` URLs instead of downloading
- **No French** — Per project policy, French is never used in the app
